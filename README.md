IFMT - Bridge (static website)
Estrutura:
- index.html, about.html, courses.html, news.html, contact.html
- css/styles.css
- js/main.js
- data/news.json
- assets/* (logos e imagens)

Para rodar localmente:
1. Coloque a pasta no servidor (Apache/Nginx) ou abra index.html no navegador.
2. Substitua imagens em assets/.
3. Para enviar o formulário de contato, integre um backend (ex.: Node/Express, Formspree, Google Forms).

Posso:
- Gerar o ZIP pronto para download.
- Substituir por cores/fonte oficiais do IFMT.
- Criar o tema WordPress ou um back-end (Node/PHP).
